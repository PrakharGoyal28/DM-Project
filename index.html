The Secret Mathematics of Mazes

Every maze hides a picture made of dots and lines. Let's find it, and learn how a computer finds the shortest way through.

A. Graphs B. Paths C. Shortest path D. BFS E. Why BFS works F. Careful! The big claim

A Graphs: dots and lines

A graph is a set of points joined by lines. Mathematicians call the points vertices and the lines edges.

  • Each open square is a vertex.
  • Each move between two neighbouring open squares (up, down, left or right) is an edge.
  • Walls are not vertices, so no edges touch them.

Switch views to see the hidden graph inside the maze!

B Paths: one step at a time

A path is a list of squares where each square is a neighbour of the one before it. In graph words: you can only travel along edges.

Walls break the connection between squares, so a path can never jump through a wall or skip a square.

C The shortest path

Lots of paths can lead to the treasure. The shortest path is the one that uses the fewest moves.

Look at Route A (orange dashes) and Route B (blue line). Predict: which one is shorter?

D Breadth-First Search (BFS)

Imagine dropping a pebble in water. The ripples spread outward in all directions. BFS explores nearby places first, then places farther away.

  1. Start at the robot.
  2. Explore all the neighbouring squares you can reach.
  3. Explore the next layer of squares.
  4. Keep going until the treasure is reached.

BFS keeps a waiting line called a queue: first in, first out, just like a line at the school canteen.

E Why BFS finds a shortest path

BFS explores all places one move away before places two moves away, all places two moves away before places three moves away, and so on.

So the first time BFS reaches the treasure, there cannot be a shorter way. A shorter way would have been found in an earlier ripple! This works when every move costs the same.

F Careful! When moves cost different amounts

BFS finds the path with the fewest moves. That is the same as the cheapest path only when every move costs the same.

Imagine some squares are sticky mud that takes 5 seconds to cross, and road squares take 1 second. Which route is best?

When moves have different costs, computer scientists use other algorithms, such as Dijkstra's algorithm. BFS is not the best tool for every maze!

The big claim (for grown-ups and curious kids)

Conjecture

In a maze where every move costs one step, BFS finds a shortest path whenever the destination is reachable.

Assumptions

  • The maze is a graph G = (V, E): open squares are vertices; orthogonally adjacent open squares are joined by an edge.
  • Movement is restricted to edges (no diagonal moves, no walls).
  • Every edge has the same cost (1 move).
  • The maze is finite and the destination is reachable from the start.

Definitions

Let dist(v) be the minimum number of moves from the start s to vertex v. Layer Ld is the set of vertices with dist(v) = d. So L0 = {s}.

Proof

  1. Divide the reachable squares into layers L0, L1, L2, … by their minimum distance from the start.
  2. The start square is the only square in layer 0, and BFS records it with distance 0.
  3. Claim (by induction on d): BFS dequeues every vertex of Ld before any vertex of Ld+1, and records distance d for each vertex in Ld. Base case: only s is in the queue at first, with distance 0. Inductive step: every vertex w in Ld+1 has a neighbour v in Ld (the square just before it on a shortest route). While BFS works through layer d, the first such neighbour to be dequeued discovers w and records distance d+1. w cannot be discovered earlier, because anything dequeued earlier is in a layer ≤ d−1, and a neighbour of such a square is at most distance d away. The queue is first-in-first-out, so all of layer d+1 joins the queue behind layer d.
  4. Every move between neighbouring squares costs exactly one step, so "distance" and "number of moves" mean the same thing.
  5. Therefore each square is first discovered along a path with the minimum possible number of moves, and its parent pointer records the last step of such a path.
  6. When BFS first reaches the destination, its recorded distance is dist(destination). Following parent pointers back gives a path of exactly that many moves: a shortest path. ∎

Why the visited set matters

A square is marked visited the moment it is discovered, and is never added to the queue again. That stops BFS from going round in circles and means each square is processed at most once, so the work is proportional to the number of squares plus connections, O(|V| + |E|).

BFS is complete

A finite maze has finitely many squares and each joins the queue at most once, so BFS always stops. If the destination is reachable, it lies in some layer Lk and is discovered by the claim above. If the queue empties first, the destination is unreachable, and the game reports exactly that.

Proof vs. testing

Testing many mazes builds confidence that our code is correct, but no number of tests covers every possible maze. The proof is what establishes the general claim. Below, the game checks its BFS against a completely different method: repeatedly relaxing distances until nothing changes, a Bellman–Ford-style computation that uses no queue. This tests the implementation. It does not prove the theorem.

How to Play

Guide Robo through the maze to the treasure chest.

1. Meet Robo

Robo starts on the flag square. Your job: reach the treasure chest.

↑←↓→

2. Move

Use the arrow keys, W A S D, the big arrow buttons, or swipe on the maze.

3. Walls block you

Dark striped squares are walls. Robo can't go through them, and bumping a wall never counts as a move.

4. Bonus gems

Gems are optional extra points. Grabbing one might mean taking a longer route. You decide!

5. Stuck? Get a hint

Hint 1 gives a tip. Hint 2 makes a square glow. Hint 3 shows a little piece of the path.

6. Earn stars

1 star for reaching the treasure, +1 for using a shortest path, +1 for using no hints.

Points

  • 100 points for finding the treasure.
  • Up to 50 bonus points for a short route (shortest path = all 50; you lose only 10 per extra move).
  • Up to 30 bonus points for not using hints (10 less for each hint).
  • 20 points for every gem.
  • 25 points for beating a move limit.

Speed is never part of your score. Take your time and explore!

Game modes

  • Adventure: play the 12 levels in order.
  • Robot Race: you play first, then the BFS robot shows its shortest path.
  • Free Play: any level, and you can reveal the shortest path whenever you like.
